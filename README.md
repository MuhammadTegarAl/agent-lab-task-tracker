# Daymark Task Tracker

A small, responsive, dependency-free task tracker. Tasks are stored in your browser using localStorage.

## Run locally

Open `index.html` in a modern browser. No build step or package installation is required.

## Tests

Run with Node.js 24 or compatible:

```sh
node --test test/logic.test.cjs
```

## Features

Add, edit, complete, delete, and filter tasks. Data remains on the current browser and device.
